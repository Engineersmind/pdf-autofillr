## [1.0.0] - 2026-04-22

### Added
- Initial release of the Python SDK
- `PDFMapperClient` for calling the PDF Autofiller mapper API
- `MapperResource` for field extraction, mapping, embedding, and filling operations
- CLI entrypoint: `pdf-autofiller`
- Examples: basic usage, context manager, config-based usage
